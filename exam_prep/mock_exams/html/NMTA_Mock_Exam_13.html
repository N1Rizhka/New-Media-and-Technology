A1 (2 marks). Heat values of a set of streams run from a minimum of 0 to a maximum of 120. An analyst discretizes them into Low, Mid and High using equal width. Into which grade does a stream with heat 85 fall?
Equal width: every interval covers the same range of values; width = (maximum − minimum) / number of grades
  1. (a) Mid: each grade is 40 wide, so Mid covers 60 to 100.
  2. (b) Mid: each grade must hold the same number of streams.
  3. (c) Low: each grade is 85 wide, so Low covers 0 to 85.
  4. (d) High: each grade is 40 wide, so High covers 80 to 120.

A5 (2 marks). An analyst compares {X} → {Y} with the reversed rule {Y} → {X} on the same baskets. Which number will in general differ between the two rules?
s(X → Y) = σ(X ∪ Y) / N; c(X → Y) = σ(X ∪ Y) / σ(X)
  1. (a) Support only, because its numerator changes from σ(X) to σ(Y).
  2. (b) Confidence only, because its denominator changes from σ(X) to σ(Y).
  3. (c) Both numbers, because a rule with a new direction counts a new itemset of baskets.
  4. (d) Neither number, because both rules are built from the same two items.
A6 (2 marks). In the course's bakery rules, matcha_powder → bamboo_whisk (support .089, confidence .810, lift 7.80) is called the strongest rule, although cake_mold → parchment_roll has higher support (.101). What best explains its top lift?
lift(X → Y) = c(X → Y) / s(Y)
  1. (a) Matcha powder is the shop's most-bought item, so every rule it starts scores well.
  2. (b) Few orders hold a whisk (about .104), yet most matcha orders do, a big gap from chance.
  3. (c) Its support is the highest in the table once rounding of the counts is taken into account.
  4. (d) Its lift is high because two-item rules always score higher than one-item rules.
