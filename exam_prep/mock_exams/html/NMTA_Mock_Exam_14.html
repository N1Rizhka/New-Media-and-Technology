A11 (2 marks). A junior analyst proposes choosing the k with the lowest within-cluster sum of squares (WCSS), since lower WCSS means tighter groups. Why does the course reject this rule?
  1. (a) WCSS always falls as k grows, so the rule always picks the largest k; at one viewer per group it is zero.
  2. (b) WCSS can only be computed for k = 2 and k = 3, so the rule cannot fairly compare larger candidates.
  3. (c) WCSS rises again once k passes the true number of groups, so the lowest value is usually a small k.
  4. (d) WCSS measures separation between groups, not tightness, so lower values mean groups that overlap more.

A13 (2 marks). A short review has the vector u = (1, 0, 2). A long review that repeats the same points has v = (3, 0, 6). What is their cosine similarity, and why?
cos θ = (a · b) / (‖a‖ ‖b‖); a · b = sum of products of matching coordinates; ‖a‖ = square root of the sum of squared coordinates.
  1. (a) 1/3, because v is three times as long as u and cosine scales with length.
  2. (b) 0, because two vectors of different length cannot point in the same direction.
  3. (c) 1, because v points the same way as u; length does not affect cosine.
  4. (d) −1, because repeating the same words points the vector the opposite way.

A15 (2 marks). Two different splits of the same collaboration network score Q = 0.42 and Q = 0.03. Which reading matches the course?
Q = (share of ties inside the groups) − (share expected inside the groups by chance).
  1. (a) The first split is tighter; the second is barely better than chance.
  2. (b) The second split is better, because a lower Q means fewer ties are cut.
  3. (c) Both are equally valid, because Q only counts how many groups were found.
  4. (d) The first split has proved that its groups are meaningful customer segments.
