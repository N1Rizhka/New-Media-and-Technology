# NMTA Mock Examination Answer Keys

Marking guides for the sixteen practice papers in `../mock_exams/`.

## How to use a key

- Attempt the matching paper first.
- Award marks for distinct points of reasoning. Equivalent accurate wording earns the stated marks; the sample sentences are not required.
- Do not award the same point twice, and do not exceed the question's total.
- For calculations, accept fractions, decimals or percentages when they support the same conclusion. Carry an earlier arithmetic slip forward without a second penalty when later reasoning correctly follows the student's own figures.
