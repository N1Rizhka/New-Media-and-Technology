Part B: Reference answers and marking guidance

B1: Who gets the invitation? (6 marks) Week 4 · Who joins the private domain: the same two errors

Reference answer. (i) False positives: invited viewers who did not return, 500 − 180 = 320; each costs staff time spent on someone who only browses. False negatives: returners not invited, 300 − 180 = 120; each is repeat revenue the group could have nurtured (messages there cost no media spend). (ii) Precision = 180 / 500 = 0.36: about one invitee in three returned. Recall = 180 / 300 = 0.60: the list reached 60 percent of returners. (iii) If staff time is scarce, false positives become dearer: raise the cut, inviting fewer viewers with higher precision and accepting more missed returners. If revenue per returner rises, false negatives become dearer: lower the cut, raising recall at the price of more staff time. As with the spam filter, the cut is set by what each error costs.
Marking. 2 marks for (i): 1 for the false positive (320, staff time), 1 for the false negative (120, lost repeat revenue). 2 marks for (ii): 1 for precision 0.36, 1 for recall 0.60. 2 marks for (iii): 1 for raising the cut when staff time is scarce, 1 for lowering it when repeat revenue rises, each with the error it trades. Accept counts and directions described as tiers rather than score cuts. Do not award (i) marks if FP and FN are swapped.

B2: Fit plus penalty: why LASSO prefers the sparser set (6 marks) Week 5 · OLS, Ridge and LASSO, and what happens as the penalty grows

Reference answer. OLS has no penalty and minimises SSE alone, so it prefers set 1 (40 < 43). LASSO penalty for set 1: 2 × (2.0 + 1.0 + 0.5) = 2 × 3.5 = 7, objective 40 + 7 = 47. Set 2: 2 × (1.5 + 0 + 0) = 3, objective 43 + 3 = 46. LASSO prefers set 2 (46 < 47): the small loss of fit is outweighed by the lower complexity cost. The intercept is not penalized (the sum starts at j = 1): it is the anchor that sets the line's level, and shrinking it would only drag predictions toward zero. The zeros remove predictors 2 and 3 from the fitted equation, so LASSO has shrunk and selected at once; that does not prove those features could never matter in other data.
Marking. 1 mark for OLS choosing set 1 by SSE. 1 mark for each LASSO penalty (7 and 3), using absolute values (the negative coefficient counts as 1.0). 1 mark for objectives 47 and 46 and choosing set 2. 1 mark for the intercept not penalized, with reason. 1 mark for the zeros removing those predictors' contribution (shrink and select). Error carried forward: if a penalty is wrong, award the choice mark when it follows from the student's objectives. Including the intercept in the penalty loses the intercept mark.

B3: When the plan asks for fewer groups than the curves (6 marks) Week 6 · Kotler's four tests and the floor

Reference answer. The floor says that if the business has a given number of campaigns planned, k is at least that number, whatever the curves say: it is a lower limit, so here k ≥ 2. It does not say k must equal the number of campaigns, so the floor does not force k down to 2; k = 3, nominated by both the silhouette peak (0.44) and the elbow, satisfies the floor. The third segment holds 0.08 × 25,000 = 2,000 users. Whether it gets a campaign depends on Kotler's four tests: it must be measurable, substantial (profitable to serve at 2,000 users), reachable and actionable, and the analyst should confirm it reappears across resamples and seeds. If it fails, it can be served low-touch or folded into a neighbouring campaign while the map keeps k = 3.
Marking. Award 1 mark for stating that the floor sets a lower limit (k at least the number of campaigns). Award 1 mark for explaining that k = 3 satisfies the floor, so the manager's reading is wrong. Award 1 mark for noting that the silhouette and elbow agree on k = 3. Award 1 mark for 2,000 users. Award 1 mark for applying the four tests to the third segment (at least two tests named and linked to the case). Award 1 mark for a stability check or a sensible fallback (low-touch service or merging into another campaign). Do not award the first mark for 'k must equal the number of campaigns'.

B4: A supervised sentiment model for an airline (6 marks) Week 7 · Method 2: supervised learning on text

Reference answer. (1) 430 / 500 = 0.86, so held-out accuracy is 86%, measured on reviews not used in training as in Week 4. (2) Holding the other features fixed, a higher "delay" weight lowers the predicted probability of positive sentiment; "seat" has a zero coefficient, so changing it does not change the predicted probability. These are associations in the model, not levers. (3) Unigram features omit word order, so "good" gets the same feature in "good crew" and "not good"; phrases should be read in real reviews before interpreting the association. Star ratings are noisy proxy labels: a sarcastic 5-star or a neutral 4-star text would teach the model the wrong lesson, so the target definition should be validated against provided labels.
Marking. Award 1 mark for 86%. Award 1 mark for the "delay" interpretation including direction and 1 mark for "seat" (zero, no change); deduct nothing extra if "holding other features fixed" is stated once for both. Award 1 mark for the word-order / negation problem with "good". Award 2 marks for label quality: 1 for stars being noisy proxy labels, 1 for a supported reason or remedy (sarcasm, neutral text at 4 stars, validate the target definition). A causal reading such as "remove the word delay to raise satisfaction" earns no interpretation mark.

B5: Visit-pattern clusters or referral communities? (6 marks) Week 8 · Clustering versus communities, and segments you did not declare

Reference answer. The two answer the same segmentation question with different data. K-means groups by features (how members train), and Louvain groups by ties (who referred whom). K-means needs k declared in advance (here 4), while Louvain finds the number of groups itself (here 7). In K-means, close means similar feature values; in a community, close means few hops on the referral map. For a bring-a-friend campaign, the communities are the better input: they are measurable, reachable segments whose ties are the very channels a referral travels along. For a job such as designing class timetables or membership tiers around how people train, the K-means segments fit better, because that decision depends on behaviour, not on who knows whom.
Marking. Award 3 marks for the three dimensions, 1 each: features versus ties; k declared versus found by the search; feature similarity versus path length. Award 2 marks for choosing the communities for the referral campaign (1) with the reason that the ties are the channels / reachable segment (1). Award 1 mark for a sensible job where feature-based segments fit better. Do not award marks for saying one method is simply 'more accurate'.

Part C: Case analysis

Case 1: Saffron Kitchen Week 4 · Who joins the private domain: the same two errors, Two ways to be wrong: the four cells, Precision and recall: who feels each, The dial is asymmetric, The accuracy trap

C1.1 (8 marks).

Model answer. At 0.5: TP = 300 (returners invited); FP = 600 − 300 = 300 (invited, did not return); FN = 400 − 300 = 100 (returners not invited); TN = 3,000 − 400 − 300 = 2,300 (not invited, did not return). Check: 300 + 300 + 100 + 2,300 = 3,000. Precision = 300 / 600 = 0.50: half of the invitees returned. Recall = 300 / 400 = 0.75: the list reached three quarters of returners. False positive: a viewer who only browses is invited, so host time is spent on someone who never buys again. False negative: a viewer who would have come back is left on public reach, so repeat revenue the group could have nurtured never arrives.
Marking. 3 marks for the matrix: 1 for TP and FP, 1 for FN, 1 for TN (2,300), with truth and verdict correctly placed. 1 mark for precision 0.50. 1 mark for recall 0.75. 3 marks for the errors: 1 for naming the FP in business terms, 1 for naming the FN in business terms, 1 for the two different costs (staff time versus lost repeat revenue). Do not award the error marks if FP and FN are swapped.

C1.2 (6 marks).

Model answer. 0.7: precision = 210 / 300 = 0.70, recall = 210 / 400 = 0.525. 0.3: precision = 360 / 1,200 = 0.30, recall = 360 / 400 = 0.90. Capacity is 700, so 0.7 (300 invited) and 0.5 (600) fit; 0.3 (1,200) does not. From 0.5 to 0.7: 210 fewer browsers invited (300 to 90) but 90 fewer returners reached (300 to 210). From 0.5 to 0.3: 60 more returners reached (300 to 360) but 540 more browsers invited (300 to 840). The steps are asymmetric: loosening the cut buys a few returners with a lot of staff time, while tightening saves staff time but gives up a large share of returners. As with the spam threshold, the cut is set by what each error costs, here within a hard staff limit.
Marking. 1 mark for both values at 0.7 and 1 mark for both values at 0.3. 1 mark for identifying that 0.7 and 0.5 fit the capacity and 0.3 does not. 1 mark for the 0.5 to 0.7 step (210 browsers saved, 90 returners lost). 1 mark for the 0.5 to 0.3 step (60 returners gained, 540 more browsers). 1 mark for interpreting the asymmetry as a trade between the two error prices. Carry forward an error from the first sub-question.

C1.3 (6 marks).

Model answer. Inviting nobody is right on all 2,600 non-returners: 2,600 / 3,000 = 0.867. It flatters because returners are a minority: it reaches 0 of 400 returners, so every false negative is incurred, and accuracy hides which error is made. Recommendation: use the score as three tiers, like a review queue. Score 0.7 and above (300 viewers, 70 percent return): invite into the group with a named host. Score 0.5 up to 0.7 (300 viewers, of whom 300 − 210 = 90 return): invite with a first repeat offer and review after one month. Below 0.5: keep on public reach, no staff time. This uses 600 of the 700 places and reaches 300 of 400 returners. Limitation: the score shows who tended to return, not that the invitation causes the return; the test used one month of viewers, so the return rates may not hold for new streams, and the tiers should be re-checked against next month's actual returns.
Marking. 1 mark for 0.867 with working. 1 mark for explaining that it reaches no returners (the number hides the error column). 2 marks for the recommendation: 1 for a tiered or cut-based design that fits within 700 places, 1 for supporting it with counts (precision, recall or returners reached). 2 marks for one explained limitation (1 for naming it, 1 for its consequence): prediction is not causation, one month of data, changing viewer behaviour, or staff costs not priced. A single cut at 0.5 or 0.7 with a costed reason can earn full recommendation marks.

Case 2: PulseRidge Week 7 · Method 1: lexicon scoring, and its failures, Method 2: supervised learning on text, Comparing the three methods and routing reviews, Method 3: zero-shot analysis with a large language model

C2.1 (8 marks).

Model answer. Version 1: R1 = love + comfy + accurate = +3, positive. R2 = great = +1, positive. R3 = bad (−1) + easy (+1) = 0, neutral. R4 = accurate (+1) + slow (−1) = 0, neutral. R5 = sick = −1, negative. Version 2: R1 +3 positive; R2 +1 positive; R3 "not bad" flips to +1, plus easy +1 = +2, positive; R4 "never accurate" flips to −1, plus slow −1 = −2, negative; R5 −1, negative. The negation rule fixes R3 and R4. Still in conflict: R2, scored positive with 1 star, is sarcasm (positive wording describing a cracked screen; "cracked" is not on the list). R5, scored negative with 5 stars, is slang ("sick" is praise here but on the negative list).
Marking. Award 2 marks for the five Version 1 scores and classes (all correct = 2; four correct = 1). Award 2 marks for Version 2: 1 for R3 = +2 positive, 1 for R4 = −2 negative (R1, R2, R5 unchanged). Award 1 mark for stating that the rule fixes R3 and R4. Award 1 mark for identifying R2 and R5 as the remaining conflicts. Award 2 marks for naming sarcasm for R2 and slang for R5 with a reason, 1 each. Apply error carried forward to the conflict identification.

C2.2 (6 marks).

Model answer. Agreement = (90 + 230) / 400 = 320 / 400 = 80%. Of the 120 negative-labeled reviews, 30 are predicted positive: 30 / 120 = 25%. Among these, inspect sarcasm (praise words describing failures, as in R2) and negation (a positive word preceded by "not" or "never", as in R4), and domain words the model may misread. Before reporting: inspect about 50 randomly selected cases, examine positive wording beside 1-star ratings, and evaluate rule or threshold changes separately before changing either; continue evaluating as language changes.
Marking. Award 1 mark for 80% and 1 mark for 25% (accept 30 of 120 with the percentage). Award 2 marks for two relevant language types with a brief reason (sarcasm, negation, slang, domain words), 1 each. Award 2 marks for validation steps: at least two of the three course steps, 1 each. Using 30 / 400 = 7.5% for the second figure earns 0 for that mark, but the remaining marks are available.

C2.3 (6 marks).

Model answer. Flagged reviews: 6% × 200,000 = 12,000; LLM cost = 12 × 4.00 = 48.00. Other reviews: 188,000 scored by the classifier = 188 × 0.10 = 18.80. Routing total = 66.80 per month, against 200 × 4.00 = 800.00 for an all-LLM approach. Adopt the rule: it follows the routing guide, sending clean standard language to a low-cost validated method and sarcasm or mixed language to LLM-assisted analysis, at a fraction of the cost, and keeps most scoring auditable. The LLM requests should specify fixed fields (sentiment, aspects, sarcasm flag, short reason). Limitation or check: the flag catches sarcasm only when a rating is available and disagrees, so sarcastic reviews without ratings are missed; LLM output consistency must be checked on repeated runs and against the review text, and the classifier's held-out errors (80% agreement) should be monitored as language changes.
Marking. Award 1 mark for 48.00 and 1 mark for 18.80 with the total 66.80. Award 1 mark for 800.00. Award 2 marks for the recommendation: 1 for a clear decision, 1 for linking it to the routing guide (situations, methods) or cost and auditability. Award 1 mark for one explained limitation or check (missed sarcasm without ratings, LLM consistency, classifier errors, maintenance). Error carried forward applies to the cost comparison.
